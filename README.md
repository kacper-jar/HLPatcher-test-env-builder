# HLPatcher Test Environment Builder

HLPatcher Test Environment Builder automatically downloads and sets up clean testing environments for HLPatcher by fetching games directly via Steam. 
It was created to eliminate the tedious process of having to manually download all of these games through the Steam client or manage pre-prepared ZIP archives every time a testing environment is needed.

> [!IMPORTANT]
> **Steam Account Prerequisites & Login Flow**
> - You must sign in with a Steam account that already owns all the games you intend to download.
> - The internal downloading tool does not keep you logged in between tasks. As a result, you will need to scan a new QR code with your Steam mobile app for each individual game as it begins downloading.
